## 🎯 Top Problems Solved

1. **How to Copy-Paste into Citrix / Remote Desktop When Clipboard is Disabled:**
   Run `GhostTasker_Pro.exe` on your local home computer, enable **Remote Desktop / Citrix Mode**, click inside your remote Citrix or RDP window, and press `F8`. Your text is typed cleanly across the session boundary.
2. **How to Fill Web Forms from Excel / CSV Automatically (No Coding or Selenium):**
   Load any `.xlsx` or `.csv` file in the **Excel to Form** tab. Click the first input box of any web portal and press `F9` (or `F10` / `F7`) to automatically type row-by-row with smart `Tab` navigation.
3. **How to Type Code into Paste-Blocked Online IDEs Without Broken Indentation:**
   Turn on **Smart IDE Mode** to strip duplicate auto-indentation and prevent messed-up brackets inside browser coding editors.
4. **Local Wi-Fi Phone Camera OCR to PC Typing:**
   Scan the built-in QR code with your phone browser to snap a photo of printed text or another screen and type it directly onto your PC.

## 🛡️ Built-In Safety & Control Features
* **Instant Panic Stop (`Esc + Esc`):** Double-tap `Esc` anytime to freeze typing immediately and save your exact word bookmark.
* **Window Lock Guard:** Automatically pauses typing if you accidentally click outside your target window.
* **Pause on Mouse Move:** Yields control instantly whenever you move your physical mouse.
